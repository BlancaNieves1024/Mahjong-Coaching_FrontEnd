# 麻雀AI牌譜添削ツール（プロトタイプ）

Flaskを使用した麻雀牌譜添削ツールのプロトタイプアプリケーションです。牌譜URLを入力し、バックエンドでの解析結果を元に手牌やアドバイスを視覚的に表示します。

---

## ディレクトリ構成

プロジェクトフォルダ内に、以下の構成でファイルを配置してください。エラーハンドリング用の `error.html` も含みます。

your_project/
  ├── app.py
  └── templates/
       ├── index.html
       ├── template.html
       └── error.html

---

## 実行手順

### 1. 必要なライブラリのインストール
Pythonがインストールされている環境で、Flaskをインストールします。

pip install flask

### 2. アプリケーションの起動
app.py があるディレクトリ（ルートディレクトリ）をターミナルで開き、以下のコマンドを実行します。

python app.py

正常に起動すると、コンソールに以下のようなログが表示されます。
 * Running on http://127.0.0.1:5000
 * Restarting with stat

### 3. ブラウザでのアクセス
ブラウザを開き、以下のURLにアクセスします。

http://127.0.0.1:5000

入力画面が表示されたら、牌譜URL（天鳳・雀魂など）を入力して「解析を開始する」ボタンを押すと、結果画面（template.html）へ遷移します。エラー発生時には専用のエラー画面（error.html）が表示されます。

---

## 💡 エラー（4XX / 5XX）のデモンストレーション・確認方法

### 404エラー（ページが見つからない場合）の確認
ブラウザで存在しないURL（例: `http://127.0.0.1:5000/invalid-url`）に直接アクセスすると、404エラー画面が表示されます。

### 500エラー（サーバーエラー）の確認
1. `app.py` の `app.run(debug=True, ...)` を **`debug=False`** に変更してサーバーを再起動します。
2. 解析処理のルート（`/analyze` 等）の中に一時的に強制エラーを発生させるコード（`raise Exception("Test Error")`）を記述します。
3. ブラウザからフォーム送信を行うと、可愛い猫のイラスト付きの500エラー画面（error.html）が再現・確認できます。
