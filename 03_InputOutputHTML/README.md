# 麻雀AI牌譜添削ツール（プロトタイプ）

Flaskを使用した麻雀牌譜添削ツールのプロトタイプアプリケーションです。牌譜URLを入力し、バックエンドでの解析結果を元に手牌やアドバイスを視覚的に表示します。

---

## ディレクトリ構成

プロジェクトフォルダ内に、以下の構成でファイルを配置してください。

your_project/
  ├── app.py
  └── templates/
       ├── index.html
       └── template.html

---

## 実行手順

### 1. 必要なライブラリのインストール
Pythonがインストールされている環境で、Flaskをインストールします。

pip install flask

### 2. アプリケーションの起動
app.py があるディレクトリ（ルートディレクトリ）をターミナルで開き、以下のコマンドを実行します。

python app.py

正常に起動すると、コンソールに以下のようなログが表示されます。
 * Running on http://127.0.0.1:5000
 * Restarting with stat

### 3. ブラウザでのアクセス
ブラウザを開き、以下のURLにアクセスします。

http://127.0.0.1:5000

入力画面が表示されたら、牌譜URL（天鳳・雀魂など）を入力して「解析を開始する」ボタンを押すと、結果画面（template.html）へ遷移します。
